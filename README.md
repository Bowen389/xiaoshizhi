# 小市值双低：20万元模拟账户

**原始规则：未复权价格最低前200 ∩ 总市值最小前200，价格严格大于2元。** 仅沪深主板，排除当前ST/*ST、退市/整理、停牌及上市未满365日；先分别排名，再过滤，不补位。等权整手，月末收盘选股，次月首个交易日开盘价模型买入，月末收盘价模型卖出。

GitHub Actions默认分支自动运行，无需自备证券账户或密钥：

| 北京时间 | 工作 |
|---|---|
| 工作日09:20 | 盘前检查 |
| 09:31 | 开盘价模型执行到期模拟买入、处理未卖持仓 |
| 14:50 | 更新估值，必要时补记同日未执行的开盘模型 |
| 15:20 | 更新净值、每日筛选、月末收盘模型卖出及冻结信号 |
| 15:50 | 收盘任务重试，订单和信号幂等 |

GitHub定时任务可能排队，**不是精确到秒的交易服务器**。这是公开数据的开收盘价模型模拟：迟到任务可在当日按已观测的开盘价补记模型成交，`observed_at`保留真正运行时间，绝不称为真实即时委托。隔日不偷偷按旧信号补买；过期买入不执行。人工补跑入口为Actions → Double-low 200k paper simulation → Run workflow。

同日信号封存后保留原候选，即使数据源事后修订，也不悄悄更换明日名单。原始股票池CSV按日期和内容哈希保存；全池行情缺失、当日有效报价不足90%、缺上市日期或关键字段时停止本次处理，不将数据故障报告为零信号。失败运行不提交账户修改，审计文件仍可从Actions附件下载。公开源若在GitHub网络不可达，任务会明确失败，需要重试；不保证每个外部接口全天可用。

2026年交易日历依据[上交所官方安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)，含节假日及周末；不将补班周末当交易日。当前日历覆盖至2026年底，2027年运行前应更新`market.HOLIDAYS`的官方安排；年份未知即停止，不猜交易日。

## 资金和费用

- 固定初始资金200000元，预算按真实剩余现金/N分配；买入100股整数倍，费用包含在预算内。
- 买卖佣金各万一，每笔最低5元；卖出印花税万一是用户自定义模拟假设；过户费双向0.01‰另计。
- 按报价中的真实涨跌停价挡单，不用固定10%猜当日限价；信号股票在买入日再次排除ST、退市及非当日行情。
- 已持有现金分红按实施记录计入，基准假设除息日到账；卖出时按持有期限计红利税。送转事件自动停止，需核对上市日和零股后适配，不能静默忽略。
- 每个订单有唯一ID，重复运行不重复买卖。无新信号不月中主动调仓；相邻月份同股先卖再买。不能卖出的旧仓不得当成现金再花。
- 净值=现金+持仓市值；陈旧行情沿用最后估值并记录`stale_codes`，不伪造成当日价格。

## 数据与复核

腾讯当前行情提供股价、开盘价、涨跌停价及总市值；东方财富提供主板股票池和上市日期、已实施分红。当前选股使用当日ST状态，不使用研究回测冻结名单。股票池按最新可用估值截面获取，再用当日全池报价筛选；当日新上市股票可能尚未进入来源截面，不保证发行首日股票占位完全一致。

`data/account.json`是持久状态；`data/orders.csv`记录模拟成交、费用、信号日与真实观测时间；`data/nav.csv`为每日净值；`data/inputs/`保留行情排名输入，`data/signals/`为冻结候选。完整报告在`reports/latest.md`。工作流串行，并只在成功后提交，推送冲突不强制覆盖远端。

## 本地运行

Python 3.12，仅标准库，没有`import os`，不连接券商、不提交实盘订单：

```bash
python -m unittest discover -s tests -v
python run.py --phase auto
```

阶段可选`preflight/open/watch/close`。程序按北京时间与当日实际交易日运行，不提供伪造历史日期成交的命令行开关。
